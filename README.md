# السينما موبايل (ArabCine)

تطبيق جوال للبث المباشر والأفلام والمسلسلات، مبني بـ Capacitor ويُبنى تلقائياً على GitHub Actions.

## طريقة البناء على جت هوب (GitHub)

1. أنشئ مستودعاً جديداً (Repository).
2. ارفع **كل** ملفات هذا المشروع بنفس أسماء المجلدات:
   - من الكمبيوتر: فك الضغط ثم اسحب كل المحتويات (بما فيها المجلد المخفي `.github`) إلى صفحة الرفع.
   - من الجوال: استخدم Add file ← Create new file واكتب المسار كاملاً في خانة الاسم (مثل `www/app.js` أو `.github/workflows/build-apk.yml`) ثم الصق المحتوى.
3. بعد الرفع افتح تبويب **Actions**، سيبدأ البناء تلقائياً (أو اضغط Run workflow). يستغرق 5 إلى 8 دقائق.
4. عند النجاح حمّل ملف **ArabCine.apk** من قسم **Releases** في الصفحة الرئيسية للمستودع، أو من Artifacts داخل تشغيل البناء.

## ملفات المشروع

| الملف | الوظيفة |
|---|---|
| `www/index.html` `www/style.css` `www/app.js` | واجهة التطبيق والمشغّل |
| `www/channels.js` | القنوات والأفلام المدمجة (عدّل الروابط من هنا) |
| `capacitor.config.json` | إعدادات التطبيق (الاسم، الصلاحيات) |
| `make_icons.py` | يولّد الأيقونة وشاشة البداية تلقائياً |
| `.github/workflows/build-apk.yml` | سكربت بناء الـ APK |

## إضافة قنوات دون إعادة بناء

من داخل التطبيق: **الإعدادات ← إضافة قائمة M3U**، أو لصق نص M3U، أو استيراد ملف، أو إضافة قائمة القنوات العربية العامة (iptv-org).

## ملاحظات

- التطبيق مشغّل فقط ولا يستضيف أي محتوى. القنوات المشفّرة أو المدفوعة تحتاج اشتراكاً رسمياً ولا يمكن تشغيلها عبر روابط عامة.
- روابط البث تتغير من الجهة المالكة؛ إذا توقفت قناة جرّب مصدراً آخر أو غيّر محرّك التشغيل من الإعدادات.
- هذا الـ APK موقّع بمفتاح الاختبار (debug) ومناسب للتثبيت المباشر. للنشر على Google Play تحتاج بناء Release بمفتاح توقيع خاص.
